## 注释风格规范（立为项目标准）

1. 文件头 = `"""模块名 — 一句话。"""` + `════` 框标题 `【L5 架构全景图】`+ ASCII 图/表格 + `【L3 核心考点索引】`
2. Section 分隔 = `# ══...══` 双线 + `§N 名称 — 说明`
3. 函数 docstring = Args/Returns + `【L3/L4/L5 考点】`标记 + 执行步骤表格 + 设计决策说明
4. 字段 docstring = `"""说明。【L3】原理。代码示例。"""`
5. 考点标签体系: `【L3 核心考点】` `【L4 工程】` `【L5 决策】` `【L5 架构】`
6. 表格 = ASCII 对齐（┌─┬─...）
7. 流程图 = Unicode box-drawing
8. 符号: `●读 ▲写 ★累加` 用于数据流
